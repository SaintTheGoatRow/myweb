My Learning Plan

Skill Improvement Steps

To ensure constant growth in web development throughout this semester, I am following this ordered progression:

  1. Strengthen HTML & CSS Fundamentals: Master semantic page structure, flexible box layouts, grid alignment, and WCAG accessibility standards.
  2. Practice Responsive Design & Animation: Develop fluid layouts that adapt across mobile devices without layout breaking or horizontal scrolling.
  3. Implement Interactive Client JavaScript: Learn DOM manipulation, asynchronous form handling, custom events, and responsive UI feedback loops.
